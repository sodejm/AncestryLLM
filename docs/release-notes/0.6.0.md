# AncestryLLM 0.6.0

AncestryLLM 0.6.0 advances the Astral tooling modernization and completes the
v0.6 Diátaxis documentation cutover alongside the v0.5.0 desktop foundation.

## Highlights

- Diátaxis information architecture applied to the documentation navigation
  and `Home.md`, with clear Diátaxis mode headings in the sidebar.
- Page-level SEO metadata sidecar (`docs/_data/page_metadata.json`) injected
  into the Pages staging tree; Wiki output remains front-matter free.
- `jekyll-seo-tag` and `jekyll-sitemap` enabled in the Pages build.
- `robots.txt` published to the documentation site.
- GitHub Pages workflow upgraded to `upload-pages-artifact` v5, which uses the
  repository-pinned `upload-artifact` v7 internally.
- `docs/DOCS_AUTHORING.md` authoring rules, Diátaxis migration inventory, and
  editorial baseline added.
- ADR-0026 records the accepted future local-container and advanced remote
  deployment architecture, ownership model, quantitative budgets, and
  threat-model gates. It does not add runtime support in this release.
- `docs/release-evidence/0.6.0/` evidence directory added.
- Repository setup, CI, release-readiness, release, desktop-sidecar, and
  release-project proof jobs verify the pinned `uv` 0.12.1 release archive,
  executable hash, and GitHub provenance before first execution.
- Sanitized schema-v1 bootstrap receipts are retained by CI and are required by
  release evidence; stock-`pip` wheel and sdist consumer smoke tests remain.

## Upgrade notes

Developer and release tooling now uses the verified repository-local `uv`
bootstrap. No ancestry CLI, REPL, API, provider, GEDCOM, storage, container, or
remote-hosting behavior has changed. The new deployment architecture record is
a future constraint, not an availability claim.
