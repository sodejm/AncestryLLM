# RootsMagic workbench — 0.7.0 development

Issue #119 adds a native local workbench for immutable RootsMagic inspection,
bounded People, Family links, and Events queries, and person-rooted GEDCOM
exports. The output is one new folder containing the GEDCOM, a conversion
report, and a digest manifest. It uses the merged #200 mutation coordinator.
Existing CLI SQL/question requests and separate export paths remain compatible.

The default export is portable GEDCOM 5.5.5 with a generic destination,
connected scope, and living people excluded. File access uses native grants;
container and external connections are capability-gated. Restart requires
reauthorization. Database and WAL snapshot checks preserve source bytes.

See the [workbench guide](../how-to/desktop-rootsmagic-workbench.md) and
[recovery contract](../reference/MUTATION_RECOVERY.md). This development note
does not announce a supported packaged release. Final canonical, desktop,
accessibility, visual, security, signed-commit, hosted-review, and target-matched
packaged acceptance evidence must be recorded before issue closure.
